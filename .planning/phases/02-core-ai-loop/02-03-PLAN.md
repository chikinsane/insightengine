  <action>
1. Create `insightengine/src/app/api/upload/route.ts` — `POST` handler:
   - Extract authenticated userId via `getAuthenticatedUserId()`, call `ensureUserExists()`
   - Parse `multipart/form-data` using `req.formData()` — get the `file` field
   - Validate MIME type: allow only `text/csv`, `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`, `application/vnd.ms-excel`. Return 400 with `{ error: 'Only CSV and Excel files are supported.' }` otherwise.
   - Validate file size: max 25MB (`25 * 1024 * 1024`). Return 400 with `{ error: 'File must be under 25MB.' }` if exceeded.
   - Convert to Buffer: `Buffer.from(await file.arrayBuffer())`
   - Detect file type from MIME or extension: CSV vs XLSX/XLS
   - Parse: call `parseCSVBuffer(buffer)` or `parseExcelBuffer(buffer)` depending on type
   - Infer schema: call `inferSchema(headers, rows)`
   - Create a data_source record in Neon: `db.insert(dataSources).values({ userId, name: file.name, type: fileType }).returning()`
   - Create a dataset record in Neon: `db.insert(datasets).values({ userId, dataSourceId, name: file.name, schema: schemaColumns (as JSONB), rowCount: rows.length, storageKey: '${userId}/${datasetId}' }).returning()`
   - Store raw file in Netlify Blobs: `uploadBlob(userId, dataset.id, buffer, { filename: file.name, mimeType: file.type })`
   - Return 201 with `{ datasetId: dataset.id, filename: file.name, rowCount: rows.length, schema: schemaColumns, hasLowConfidence: schemaColumns.some(c => c.confidence === 'LOW'), schemaConfirmed: false }`
   - Note: Do NOT use `export const runtime = 'edge'` — Netlify Blobs requires Node.js Lambda runtime

2. Create `insightengine/src/app/api/datasets/route.ts` — `GET` handler:
   - Authenticate, list datasets for userId from Neon: `db.select().from(datasets).where(eq(datasets.userId, userId))`
   - Return JSON array

3. Create `insightengine/src/app/api/datasets/[id]/route.ts` — `GET` and `DELETE` handlers:
   - `GET`: Authenticate, fetch dataset by id, verify `dataset.userId === userId` (tenant isolation), return dataset
   - `DELETE`: Authenticate, verify ownership, delete blob via `deleteBlob(userId, id)`, delete dataset record, return 204

4. Create `insightengine/src/app/api/datasets/[id]/confirm-schema/route.ts` — `POST` handler:
   - Authenticate, verify dataset ownership
   - Body: `{ schema: SchemaColumn[] }` — the user's confirmed/overridden schema
   - Update dataset record: `db.update(datasets).set({ schema: confirmedSchema }).where(eq(datasets.id, id))`
   - Add a `schemaConfirmed` field: since the datasets table doesn't have this column, store it as a flag inside the schema JSONB: `{ columns: [...], confirmed: true }`
   - Return 200 with updated dataset

All routes follow the same error handling pattern as `src/app/api/data-sources/route.ts`: try/catch, UNAUTHENTICATED -> 401, else -> 500.

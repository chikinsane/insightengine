  <action>
Create `insightengine/src/app/api/datasets/[id]/query/route.ts` — `POST` handler:

1. Authenticate via `getAuthenticatedUserId()`, `ensureUserExists()`
2. Fetch dataset by `id` param, verify `dataset.userId === userId` (tenant isolation)
3. Check schema confirmation: parse `dataset.schema` JSONB, check `schema.confirmed === true`. If not confirmed, return 400: `{ error: 'Schema must be confirmed before querying. Please review and confirm the column types.' }`
4. Extract `{ question, previousContext }` from request body. `question` is required (string, 1-500 chars). `previousContext` is optional (for follow-up queries — contains prior question + result summary).
5. Download file from Netlify Blobs: `downloadBlob(userId, id)`
6. Determine file type from dataset record (stored in data_source type field or dataset name extension)
7. Extract schema columns from confirmed schema JSONB
8. Build enhanced question if previousContext exists: prepend context summary
9. Call `executeWithRetry(question, columns, dataset.rowCount, fileBuffer, id, fileType)`
10. Call `runParallelEnrichment(result, question)` with the query result
11. Save query record to Neon: `db.insert(queries).values({ userId, datasetId: id, naturalLanguage: question, generatedSql: sql, vizType: enrichment.vizType })`
12. Save result to cache: `db.insert(resultsCache).values({ queryId, userId, resultJson: { result, enrichment } })`
13. Return 200 with:
```json
{
  "queryId": "...",
  "sql": "...",
  "explanation": "...",
  "result": { "columns": [...], "rows": [...], "rowCount": N },
  "enrichment": {
    "insight": "...",
    "vizType": "bar",
    "followUpQuestions": ["...", "...", "..."],
    "chartConfig": { "xKey": "...", "yKey": "...", "title": "..." }
  }
}
```

14. Error handling: wrap in try/catch. On "Could not generate a valid query after 3 attempts" error, return 422 with `{ error: 'Unable to answer this question. Try rephrasing or ask something simpler about your data.' }`. On UNAUTHENTICATED -> 401. On other errors -> 500.

15. Add `export const maxDuration = 60` for Netlify function timeout extension.

Do NOT use `export const runtime = 'edge'` — DuckDB and Netlify Blobs require Node.js Lambda runtime.

1. Create `insightengine/src/types/query.ts` with ALL shared types for Phase 2:

```typescript
export type VizType = 'bar' | 'line' | 'pie' | 'scatter' | 'table'
export type ConfidenceLevel = 'HIGH' | 'MEDIUM' | 'LOW'

export interface SchemaColumn {
  name: string
  inferredType: 'string' | 'number' | 'date' | 'boolean'
  confidence: ConfidenceLevel
  sampleValues: string[]
  nullRate: number
}

export interface ColumnMeta {
  headers: string[]
  rows: string[][]
}

export interface QueryResult {
  columns: { name: string; type: string }[]
  rows: Record<string, unknown>[]
  rowCount: number
  sql: string
}

export interface EnrichmentResult {
  insight: string
  vizType: VizType
  followUpQuestions: string[]
  chartConfig: {
    xKey: string
    yKey: string
    title: string
  }
}

export interface ValidationResult {
  valid: boolean
  reason?: string
}
```

2. Create `insightengine/src/lib/storage/blob-store.ts`:
- `uploadBlob(userId: string, datasetId: string, buffer: Buffer, metadata: { filename: string; mimeType: string }): Promise<void>` — uses `getStore('user-uploads')` from `@netlify/blobs`, key = `${userId}/${datasetId}`
- `downloadBlob(userId: string, datasetId: string): Promise<Buffer>` — returns buffer, throws if not found
- `deleteBlob(userId: string, datasetId: string): Promise<void>`

3. Create `insightengine/src/lib/ingestion/csv-parser.ts`:
- `parseCSVBuffer(buffer: Buffer): Promise<ColumnMeta>` — PapaParse with `dynamicTyping: false`, `skipEmptyLines: true`, streaming mode via `Readable.from(buffer)`. First row = headers, rest = rows. Return `{ headers, rows }`.

4. Create `insightengine/src/lib/ingestion/excel-parser.ts`:
- `parseExcelBuffer(buffer: Buffer): ColumnMeta` — SheetJS `XLSX.read(buffer, { type: 'buffer' })`, take first sheet, `sheet_to_json(sheet, { header: 1, defval: '' })`, first row = headers (cast to String), rest = rows.

5. Create `insightengine/src/lib/ingestion/schema-inference.ts`:
- `inferColumnType(values: unknown[]): { type: SchemaColumn['inferredType']; confidence: ConfidenceLevel }` — implements the exact algorithm from research:
  - All null/empty -> string, LOW
  - Leading zeros detected in ANY value -> string, HIGH (not number!)
  - Strip currency symbols ($, EUR, GBP) and commas before number check
  - Number pct >0.95 -> number, HIGH; >0.7 -> number, LOW
  - Date pct >0.9 -> date, HIGH; >0.6 -> date, MEDIUM
  - Boolean set check (true/false/1/0/yes/no) >0.95 -> boolean, HIGH
  - Default -> string, HIGH
- `inferSchema(headers: string[], rows: string[][], sampleSize?: number): SchemaColumn[]` — samples first 200 rows (or sampleSize), calls inferColumnType per column, populates sampleValues (first 5 non-null), computes nullRate.
